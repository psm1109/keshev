# Alekov 원문 전달 도구

학생이 선택한 Git 커밋의 원문을 서버에 전달하기 위한 로컬 도구입니다.
학생 코드를 실행하지 않으며 PC 판정기나 Docker 도구가 아닙니다.

1. 이 ZIP을 학생 프로젝트 밖의 폴더에 압축 해제합니다. Node.js 22~24와 Git이 필요합니다.
2. 등록된 학생 프로젝트의 최상위 폴더에서 터미널을 엽니다.
3. 아래 명령에서 도구와 출력 파일의 절대 경로를 본인 PC에 맞게 바꿉니다.

   node "C:\도구\alekov-source-tool\student-source-cli.mjs" --output "C:\제출자료\alekov-source.json"

출력 폴더는 미리 만들고, 학생 프로젝트 밖의 새 파일 이름을 지정하세요.
기존 파일은 덮어쓰지 않습니다. 기본값은 HEAD이며, 다른 커밋은 --commit 뒤에 40자리 해시를 붙입니다.
미커밋 작업은 포함하지 않으며 기존 작업 파일과 Git 기록을 수정하지 않습니다.

생성된 JSON을 학생 포털의 '비공개 저장소 원문 묶음'에서 선택해 제출하세요.
포털은 저장소·커밋을 먼저 접수하고 원문을 따로 전달합니다. 이미 접수한 원문은 '원문만 다시 보내기'로 다시 전달할 수 있습니다.
업로드 후 서버의 AI가 과제 원문과 학생 코드를 검토합니다. 학생 코드는 실행하지 않습니다.
원문 전달 성공은 통과가 아닙니다. 판정과 진도는 포털의 서버 상태에서 확인하세요.
이 CLI 자체는 업로드나 과제 제출을 하지 않습니다. 실행 방법은 --help로도 확인할 수 있습니다.
