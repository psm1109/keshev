# PC 측정값 비교 기록

2026년 10월 29일, 이 프로젝트의 `on-client/src/server.mjs`가 실행 중인 같은 Windows PC에서 읽기 전용으로 확인했다. 아래는 예시가 아닌 당시 측정값이며, 시간에 따라 달라진다. 앱의 시각은 전체 조회가 끝난 시각으로, 항목별 측정이 동시에 이루어졌다는 뜻은 아니다. 용량은 1 GiB = 1024³ 바이트 기준이다.

앱의 조회 완료 시각은 16:38:10.730, Windows 시스템 정보 확인 시각은 16:38:17.459이다. Windows 값은 CIM 시스템 및 논리 디스크 정보에서 읽었다. 앱이 사용하는 디스크가 C:임을 확인하고 같은 드라이브를 비교했다.

CPU는 별도로 비교했다. 앱은 16:39:18.622 조회 완료 시 42.4%, Windows 성능 카운터는 16:39:19.842에 4.4%였다. 측정 시점과 표본 구간이 달라 값이 일치한다고 볼 수 없다. 앱은 약 0.2초 동안의 CPU 사용량을 계산하고, 이 비교의 Windows 카운터는 약 1초 구간을 사용했다.

이 기록은 Windows 시스템 정보와 성능 카운터를 이용한 비교다. 작업 관리자 및 디스크 속성 화면과의 직접 비교는 별도로 확인해야 한다. 작업 관리자에서 CPU와 메모리를 확인하고 C: 드라이브 속성에서 여유·전체 용량을 확인할 때 앱의 조회 완료 시각과 기준 단위를 함께 기록한다.
