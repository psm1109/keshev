# 화면 테마

처음 접속하면 다크 모드입니다. 머리글의 「기본 모드로」·「다크 모드로」 버튼으로 전환합니다.
선택은 같은 브라우저의 로컬 저장소에 보관하며, 저장이 차단돼도 현재 화면의 전환은 동작합니다.

학생 꾸밈의 배경·카드·강조색은 `student/appearance.json`에서 읽습니다.
기본 모드는 밝은 배경에 맞춘 기존 대비 보정을 사용하고, 다크 모드는 어두운 바탕과 밝은 글자의 대비를 별도로 보정합니다.
허용·차단·주의·확인 불가의 의미와 조회 기능은 그대로 유지합니다.

이번 변경은 프로젝트 소스의 화면 개선입니다. 제공 「내 PC 상태」의 측정 기능을 새로 구현한 것이 아닙니다.
설치형 앱은 승인된 실행 환경의 제공 화면을 사용하므로, 이 소스 변경이 설치본에 반영됐다고 간주하지 않습니다.
설치형 반영과 실제 완성본 확인은 승인된 실행 환경에서 별도로 진행해야 합니다.

코드 검증: 앱 폴더에서 `node --test test/theme.test.mjs`
