[목표]
앱 서버가 실행되는 내 Windows PC의 환경을 실제로 조회해서
상태 카드와 표로 보여주는 관제 대시보드를 만들어 줘.

[화면 구성]
- 맨 위: CPU·메모리·디스크·네트워크 상태 카드 네 개
- 추가 항목: Windows 방화벽과 Windows 기록
- 아래: 측정값 추이와 조회 기록
- 각 항목에 값·단위·측정 시각·출처·확인 불가 사유를 표시해 줘.

[기능]
1. CPU·메모리·디스크 사용량과 여유 공간을 보여 줘.
2. 네트워크 구성, 연결 상태, 조회 가능한 송수신 속도를 구분해 줘.
3. Windows 방화벽의 Domain·Private·Public 상태를 보여 줘.
4. 최근 24시간 System·Application 로그의 경고·오류 건수와
   조회 범위, 일부 집계 여부를 보여 줘.
5. 직접 조회한 값으로 추이를 만들고 성공·부분 결과·실패를 기록해 줘.

[데이터 표시 원칙]
- 실제 측정값과 설명용 예시 값을 화면과 설명에서 구분해 줘.
- 클라우드에서 측정한 값을 내 PC 실측이라고 표시하지 마.
- 조회 실패·권한 부족·운영체제 미지원은 확인 불가로 표시해 줘.
- 확인하지 못한 값을 0·정상·안전으로 바꾸지 마.
- 네트워크 구성이나 방화벽 상태를 PC 전체의 안전 판정으로 설명하지 마.
- 제공된 ‘내 PC 상태’ 기능과 내가 직접 개선한 부분을 구분해 줘.

[수정 범위]
- 추가 화면과 기능은 기존 student/extension.mjs에서 이어서 구현해 줘.
- 이름·색·아이콘·허용된 배치는 student/appearance.json을 사용해 줘.
- 제공 코드 수정이 필요하면 이유와 대안을 먼저 설명해 줘.
- 고치기 전에 수정할 파일 목록과 이유를 보여 주고,
  내가 확인한 다음에 수정해 줘.
- 포장 없이 기존 프로젝트 폴더에서 실행해. 포장 명령은 실행하지 마.

[검증과 결과물]
- 실제로 확인한 기능, 검증용 응답으로 확인한 기능,
  내 Windows PC에서 추가 확인할 기능을 나누어 적어 줘.
- 같은 결과를 다시 요청할 수 있도록 최종 구현을 반영한
  재현 프롬프트를 작성해 줘.
- 재현 기준 커밋, 수정 파일, 예상 화면, 기능별 확인 기준을 포함해 줘.
- 터미널 실행 명령은 재현 프롬프트와 별도로 적어 줘.
